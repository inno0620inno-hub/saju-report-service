# 사주 리포트 서비스 — 배포 가이드

지금까지 만든 걸 실제로 "살아있는 서비스"로 만들려면 아래 순서대로 진행하면 됩니다.
코드는 이미 다 준비돼 있고, 아래는 **계정 개설 + 값 채워넣기** 위주의 작업입니다.

---

## 전체 그림

```
[고객] → landing.html (신청폼)
             ↓ POST
        server.py (신청 접수 + 예약 처리)
             ↓
   saju_core.py (계산) → generate_report.py (AI 해석) → build_report.py (PDF)
             ↓
   notify.py → 카카오 알림톡 + 이메일 발송
```

---

## 1단계. 로컬에서 먼저 테스트하기

```bash
cd webapp
pip install -r requirements.txt
cp .env.example .env
# .env 파일을 열어서 ANTHROPIC_API_KEY만 우선 채워넣기 (나머지는 나중에)

uvicorn server:app --reload
```

브라우저에서 `landing.html`을 열고(또는 간단히 `python3 -m http.server`로 서빙),
`API_ENDPOINT`를 `http://localhost:8000/api/submit`으로 바꾼 뒤 테스트 신청을 넣어보면
카카오/이메일 설정이 안 되어 있어도 **PDF는 정상 생성**되는 걸 확인할 수 있습니다
(발송 부분만 에러가 나고, `orders.db`에 기록이 남습니다).

---

## 2단계. 꼭 필요한 계정/키 준비

| 항목 | 어디서 | 용도 |
|---|---|---|
| Anthropic API 키 | console.anthropic.com | AI 해석문 생성 |
| 이메일 계정 (Gmail 등) | 구글 계정 설정 → 앱 비밀번호 | PDF 이메일 발송 |
| 카카오 비즈니스채널 | business.kakao.com | 알림톡 발신 주체 등록 |
| 솔라피(또는 알리고 등) | solapi.com | 알림톡을 실제로 보내주는 대행 API |
| 사업자등록 | (선택, 초반엔 생략 가능) | 통신판매업 신고 시 필요 — 이전 대화 참고 |

**카카오 알림톡은 시간이 좀 걸려요.** 템플릿 사전 심사가 보통 1~2일 걸리니,
서비스 오픈일보다 며칠 전에 미리 신청해두는 걸 추천합니다. 심사 기다리는 동안은
`disableSms` 옵션이나 이메일 발송만으로도 서비스를 시작할 수 있어요.

---

## 3단계. 서버 호스팅에 올리기

로컬(내 컴�터)에서만 돌리면 컴퓨터를 끄는 순간 서비스가 멈춰요. 아래 중 하나를 추천합니다
(전부 신용카드 없이 무료로 시작 가능한 곳들):

- **Railway** (railway.app) — 가장 쉬움, GitHub 연동만 하면 자동 배포
- **Render** (render.com) — 무료 티어 있음
- **국내: 카페24, 가비아 등 클라우드 서버** — 한국 고객 대상이면 속도상 유리

배포할 때 `.env`에 넣었던 값들을 각 서비스의 "환경변수(Environment Variables)" 설정
화면에 그대로 입력하면 됩니다.

---

## 4단계. 랜딩페이지 연결

`landing.html` 안의 이 부분을:
```js
const API_ENDPOINT = "https://YOUR_SERVER_DOMAIN/api/submit";
```
실제 배포한 서버 주소로 바꾼 뒤, `landing.html`을 :
- Cafe24/카페24 쇼핑몰의 정적 페이지로 올리거나
- Netlify/Vercel(무료)에 그냥 파일 하나 업로드하거나
- 워드프레스 등 기존 홈페이지에 iframe으로 삽입

어떤 방식이든 됩니다. **HTML 파일 하나**라 어디에든 붙일 수 있어요.

---

## 5단계. 결제 붙이기 (아직 미구현)

지금은 "신청하기"를 누르면 결제 없이 바로 리포트가 생성돼요. 실제 판매 단계에서는
신청 버튼 전에 결제 단계가 하나 더 필요합니다. 토스페이먼츠 같은 PG사의 "결제창 연동"을
붙이고, 결제 성공 콜백을 받은 뒤에 `/api/submit`을 호출하도록 landing.html의 JS를
조금 수정하면 됩니다. (이 부분은 다음에 이어서 만들 수 있어요.)
